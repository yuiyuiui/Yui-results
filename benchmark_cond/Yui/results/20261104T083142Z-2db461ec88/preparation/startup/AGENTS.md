# Yui benchmark scope

This directory serves only the Yui benchmark. The single execution procedure is
[README.md](README.md); explicit run choices are in [settings.json](settings.json).
Read both before action. Follow the entry from a fresh task when the user asks
to execute it; no generated task prompt or further start confirmation is needed.
Editing documentation or running software tests is not a benchmark launch.

Use only the exact registered rigorous-proof installation and its bundled rules.
Do not add personal proof skills, peer handoff protocols, extra tasks, comparison
material or another execution framework. The invoking task owns source readback,
dispatch and observation; Yui owns isolated proof/review work and ordinary repair.

Each new run starts from the original PDF through the entry's full-paper source
preparation. Never import another run's target, transcription, proof, source cache
or review as construction input. All generated artifacts belong to that run.
Keep old results immutable and outside construction; inspect them only for
separately requested historical analysis after the relevant runs terminate.

Do not edit this entry, configuration, helpers, bound inputs or runtime to get an
active benchmark past a failure. Follow README's retained-error, user-decision,
cancellation and terminal-close boundaries. Preserve mathematical status, source
qualification, execution health and incomplete usage as distinct evidence.
